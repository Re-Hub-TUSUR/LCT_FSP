# Карта страниц

Пустой список называет следующий шаг. Норматив — FR-О-11.

## Общие

| ID | Страница | Главное действие | Пусто и ошибки |
|----|----------|------------------|----------------|
| П-О-01 | Главная | «Я ищу работу» или «Я нанимаю» | Нет |
| П-О-02 | Регистрация | «Продолжить» | Почта занята — предложить вход |
| П-О-03 | Подтверждение почты | Ввести код | Код неверный — «Отправить письмо ещё раз» |
| П-О-04 | Вход | «Войти» | Почта не подтверждена — код ещё раз |
| П-О-05 | Чаты | «Отправить» | Чат откроется после принятия или взаимного интереса |
| П-О-06 | Календарь | «Подтвердить» или «Назначить встречу» | «Встреч пока нет» |
| П-О-07 | Ошибка | «На главную» | Чужой объект недоступен |

Меню кандидата: лента и свайпы вакансий, отклики взаимного интереса, тестирование, календарь, кабинет.
