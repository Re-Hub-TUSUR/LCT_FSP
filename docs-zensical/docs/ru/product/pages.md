# Карта страниц

Одно главное действие на странице. Пустое состояние называет следующий шаг и содержит кнопку к нему. Норматив пустых состояний — FR-О-14.

## Общие

| ID | Страница | Главное действие | Пусто и ошибки |
|----|----------|------------------|----------------|
| П-О-01 | Главная | «Я ищу работу» или «Я нанимаю» | Нет |
| П-О-02 | Регистрация | «Продолжить» | Почта занята — вход и восстановление; неверный формат — подсказка |
| П-О-03 | Подтверждение почты | «Сохранить пароль» | Ссылка старше 24 часов — «Отправить письмо ещё раз» |
| П-О-04 | Вход | «Войти» | 5 ошибок — блок на 15 минут; почта не подтверждена — письмо ещё раз |
| П-О-05 | Восстановление пароля | «Отправить ссылку» | Неизвестный адрес отвечает так же, как известный |
| П-О-06 | 2FA | «Подтвердить код» | Неверный код — счётчик; нет приложения — резервный код |
| П-О-07 | Чаты | «Отправить» | Чат откроется после принятия; файл больше 10 МБ — ошибка у поля |
| П-О-08 | Расписание | Кандидат: «Подтвердить». Работодатель: «Назначить встречу» | «Встреч пока нет. Встречу назначает рекрутер в чате» |
| П-О-09 | Уведомления | «Открыть» | «Новых событий нет» |
| П-О-10 | Ошибка | «На главную» или «Повторить» | 403, 404, 500, нет связи |
| П-О-11 | Аккаунт заблокирован | «Написать в поддержку» | Причина и срок |
| П-О-12 | Жалоба | «Отправить жалобу» | Без причины кнопка неактивна |
| П-О-13 | Документы | «Скачать PDF» | Политика и тексты согласий с версиями |
