# Карта страниц

Пустой список называет следующий шаг. Норматив — FR-О-11.

## Общие

| ID | Страница | Главное действие | Пусто и ошибки |
|----|----------|------------------|----------------|
| П-О-01 | Главная | «Я ищу работу» или «Я нанимаю» | Нет |
| П-О-02 | Регистрация | «Продолжить» | Почта занята — предложить вход |
| П-О-03 | Подтверждение почты | Ввести код | Код неверный — «Отправить письмо ещё раз» |
| П-О-04 | Вход | «Войти» | Почта не подтверждена — код ещё раз |
| П-О-05 | Чаты | «Отправить» | Чат откроется после принятия или взаимного интереса |
| П-О-06 | Календарь | «Подтвердить» или «Назначить встречу» | «Встреч пока нет» |
| П-О-07 | Ошибка | «На главную» | Чужой объект недоступен |
| П-О-08 | Возврат из Яндекса | Сессия открывается сама | «Сначала зарегистрируйтесь» |
| П-О-09 | Окно бана | Нет: закрыть нельзя | Чёрное окно, красная рамка, сверху X_X. «Вы были забанены по следующей причине». Почта поддержки — ссылка |

Меню кандидата: лента и свайпы вакансий, отклики взаимного интереса, тестирование, календарь, кабинет.

| ID | Страница | Главное действие | Пусто и ошибки |
|----|----------|------------------|----------------|
| П-К-01 | Резюме | «Сохранить резюме» | Город выбирается из списка. PDF без ключа модели — форма вручную |
| П-К-02 | Кабинет | Открыть резюме или ФСП | Нет категории — пройти тест |
| П-К-03 | Тестирование | «Начать тест» | Кулдаун — дата следующей попытки |
| П-К-04 | Выбор грейда | Выбрать стажёр, junior, middle, senior или lead | Пять грейдов |
| П-К-05 | Тест | «Отправить решение» | Черновик сохраняется при уходе. Тест не засчитан, если верных ответов на вопросы меньше минимума |
| П-К-06 | Собеседование с ИИ | «Отправить ответы» | Без ключа модели этот шаг не удерживает грейд |
| П-К-07 | Мои категории | «Пройти тест на другой грейд» | Кулдаун — кнопка ждёт дату |
| П-К-08 | Приглашения на «Обзоре» кабинета | «Открыть приглашение» | «Приглашений пока нет» |
| П-К-09 | Карточка приглашения | «Принять» | Уже отвеченное — только просмотр |
| П-К-10 | Тестовые | «Начать» | «Тестовых пока нет» |
| П-К-11 | Вакансии | Лайк или пропуск | Нет совпадений — «Сбросить фильтры». Списков «Отобрано», «Взаимно», «Не интересно» на ленте нет |
| П-К-12 | Взаимный интерес | «Открыть чат» | Пока никто не ответил взаимностью |
| П-К-13 | Поиск работы | «Не ищу работу» | Профиль пропадает из банка |
| П-К-14 | ФСП | «Привязать ФСП ID», затем «Войти» демо-логином | Пустой реестр — не ошибка. Неверный пароль — «Неверный логин или пароль» |
| П-К-15 | Мои отклики | В чате «Принять» или «Отклонить» встречу | «Взаимных отметок пока нет» |

Меню работодателя: лента, свайпы, отклики, вакансии, ATS, тестовые, календарь, кабинет.

| ID | Страница | Главное действие | Пусто и ошибки |
|----|----------|------------------|----------------|
| П-Р-01 | Профиль компании | «Сохранить» | Без профиля приглашение не уходит |
| П-Р-02 | Свайпы | «Интересно» или «Пропустить» | Колода просмотрена |
| П-Р-03 | Лента кандидатов | Открыть карточку | Фильтр сузил выдачу до нуля. Списков «Отобрано», «Взаимно», «Не интересно» на ленте нет |
| П-Р-04 | Карточка кандидата | «Пригласить» | Контакты после «Принять» |
| П-Р-05 | Форма приглашения | «Отправить приглашение» | Уже есть неотвеченное приглашение |
| П-Р-06 | Приглашения на «Обзоре» кабинета | «Открыть чат» | «Вы ещё никого не пригласили» |
| П-Р-07 | Вакансии | «Опубликовать» | Город офиса выбирается из списка. Черновик не в ленте |
| П-Р-08 | Тестовые | «Отправить тестовое» | «Тестовых пока нет» |
| П-Р-09 | ATS | «Опросить» | Сначала «Подключить демо» |
| П-Р-10 | Мои отклики | «Я понравился» показывает новый отклик сразу. «Назначить встречу». Кнопок «Принять» и «Отклонить» в чате нет | «Пока пусто», «Взаимных отметок пока нет» |

Меню администратора: задания, аналитика, «Работодатели под подозрением», банлист, справочники, параметры, журнал.

| ID | Страница | Главное действие |
|----|----------|------------------|
| П-А-01 | Банк заданий | «Добавить задание» |
| П-А-02 | Аналитика заданий и тестов на грейд | Снять срез |
| П-А-03 | Проверка компании | Подтвердить или отказать. Без файлов заявки нет |
| П-А-04 | Банлист | Заблокировать. Колонка «Кого затрагивает» — роль и почта |
| П-А-05 | Справочники | Добавить значение |
| П-А-06 | Параметры | Сохранить с комментарием |
| П-А-07 | Журнал | Открыть запись |
| П-А-08 | Работодатели под подозрением | Открыть карточку. Список пополняется без «Пересчитать» |
