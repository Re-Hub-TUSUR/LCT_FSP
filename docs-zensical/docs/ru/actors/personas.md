# Акторы и персоны

Роли по [FR-О-03](../business/brd/01-auth.md): один аккаунт — одна роль. Администратор не читает чаты.

## Карта

| Актор | Канал | Главный экран |
|-------|--------|----------------|
| Кандидат | Кабинет | Резюме, тест, приглашения |
| Работодатель | Кабинет | Свайпы и лента |
| Администратор | Админка | Банк заданий |
| Почта | Письмо с кодом | Подтверждение регистрации |
| FSP ID | Привязка профиля | Не заменяет регистрацию по почте |

## Кандидат

Хочет, чтобы работодатели находили его по подтверждённому грейду, а не по удачной формулировке резюме.

| Область | Что делает |
|---------|------------|
| Старт | Почта, пароль и согласие, затем код из письма |
| Резюме | Форма или файл. Второе резюме — другая профессия |
| Тест | Выбор грейда, задания, при рабочем коде — текстовые вопросы |
| Приглашения | «Принять» или «Отклонить». Принятие открывает контакты и чат |
| Настройки | «Не ищу работу», связь с ФСП |

## Работодатель

Хочет найти человека в банке и пригласить его с понятной вилкой.

| Область | Что делает |
|---------|------------|
| Старт | Почта, пароль, профиль компании |
| Поиск | Лента с фильтрами и свайпы «Интересно» / «Пропустить» |
| Контакт | Приглашение с вилкой. Контакты появляются после ответа кандидата |
| Дополнительно | Вакансия, встреча, тестовое, опрос ATS |

Без заполненного профиля компании приглашение не уходит.

## Администратор

Одна роль на банк заданий, аналитику, проверку компаний, банлист, справочники, параметры и журнал. Вход — окно браузера на поддомене `admin`. Второй фактор не требуется.
