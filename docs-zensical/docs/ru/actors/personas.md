# Акторы и персоны

Роли по [FR-О-05](../business/brd/01-auth.md): один аккаунт — одна роль. Администратор не читает чаты, кроме фрагмента, который приложили к жалобе.

## Карта

| Актор | Канал | Главный экран |
|-------|--------|----------------|
| Кандидат | Кабинет | «Приглашения» |
| Работодатель | Кабинет | «Потребности» |
| Администратор | Админка | «Дашборд валидации» |
| Почта | Письма | Подтверждение, уведомления |
| FSP ID | Внешний вход для привязки | Не заменяет регистрацию по почте |

## Кандидат

Хочет, чтобы работодатели находили его по подтверждённому грейду, а не по удачной формулировке резюме.

| Область | Что делает |
|---------|------------|
| Старт | Почта и согласие, затем пароль по ссылке из письма |
| Резюме | Форма или PDF. До N_резюме резюме, у каждого своя специализация |
| Тест | Опрос, выбор грейда, камера, микрофон, весь экран, затем задачи и голосовое ИИ-интервью |
| Приглашения | Принять, отклонить или пожаловаться. Принятие открывает контакты и чат |
| Настройки | Что видно до раскрытия контактов, пауза «Не ищу работу», связь с ФСП, удаление аккаунта |

2FA для кандидата по желанию.

## Работодатель

Хочет за несколько шагов описать роль и пригласить человека с понятной причиной, почему он в подборке.

| Область | Что делает |
|---------|------------|
| Старт | Почта, пароль, обязательная 2FA, профиль компании |
| Потребность | Роль, грейды, стек, команда, вилка. Пока не опубликована, кандидаты её не видят |
| Подборка | Категории, список или карточки, избранное и скрытые по этой потребности |
| Контакт | Приглашение с вилкой. Контакты появляются после ответа кандидата |
| Дополнительно | Публикация вакансии, встреча, тестовое, регулярная задача, закрытие потребности |

Без заполненного профиля компании приглашения недоступны.

## Администратор

Одна роль со всеми правами админки. Добавляет только другой администратор. 2FA обязательна. Последнего администратора удалить нельзя, себя заблокировать нельзя.

| Область | Что делает |
|---------|------------|
| Задания | Паттерн, варианты, калибровка на LLM-персонах, проверка «одного промпта», утечки |
| Прокторинг | Очередь попыток с флагами, решение в срок T_проверки |
| Люди и компании | Жалобы, подозрительные работодатели, банлист |
| Настройки | Справочники, параметры, журнал, эталонные наборы, метрики К1 и К2 |
