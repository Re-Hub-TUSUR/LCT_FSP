# ATS

Полный контракт — `docs/ATS_INTEGRATION.md`. Здесь короткий контур.

Работодатель подключает ATS и опрашивает её. Отклики разбираются нашими фильтрами: обязательные навыки, вилка, город. Результат — оценка, решение и причины. Тег, заметка и оценка уходят обратно в ATS.

Банк кандидатов платформы этот поток не меняет. Внешний человек не становится пользователем KADRY.

Сейчас провайдер — `ATS_MODE=mock`, три демо-отклика внутри API. Второй режим `fixture` читает JSON с другими именами полей и проходит тот же протокол. Живой ATS с документацией API добавляется одним адаптером в `backend/app/integrations/ats/`, без правки пайплайна.

Опрос идёт с курсора на подключении компании. Повтор того же события второй разбор не ставит. Страница в кабинете — «ATS».
