# Глоссарий

Слова продукта. Строки интерфейса в кавычках — как на экране.

| Термин | Значение |
|--------|----------|
| Категория | Специализация плюс подтверждённый грейд, например «Backend · Middle». Ставится засчитанным тестом. Текст резюме на неё не влияет |
| Грейд | Один из пяти: стажёр, junior, middle, senior, lead. Подтверждённый грейд ставит тест. Система сама грейд не понижает |
| Не подтверждён | Нет засчитанной попытки. Профиль в банке виден, категории нет |
| Банк | Лента опубликованных профилей для работодателя. Внешний отклик ATS сюда не попадает |
| Вакансия | Карточка, которую работодатель опубликовал. Кандидат лайкает её или пропускает |
| Приглашение | Сообщение компании одному человеку: текст, вилка, способ связи. Статусы: «Отправлено», «Принято», «Отклонено» |
| Контакты раскрыты | Кандидат нажал «Принять» у приглашения этой компании. До этого почты в карточке нет |
| Взаимный интерес | Компания и кандидат отметили друг друга. Открывается чат |
| Интервью | 2–3 текстовых вопроса по коду после теста, который сдан по баллам. Не голос и не созвон |
| Проходной балл | Балл из 100, с которого тест засчитан. Вопросы дают 80 % балла, задача на код — 20 %. У каждого грейда свой порог |
| Минимум по вопросам | Доля верных ответов на вопросы, без которой тест не засчитан при любом балле: 50 % у стажёра, junior и lead, 60 % у middle и senior |
| Бета-грейд | Грейд, подтверждённый тестом в бета-версии. Сейчас это lead. Работодатель видит пометку «бета» |
| «Найди ошибку» | Задача на код, где редактор открывается с почти верной программой. Балл по-прежнему ставят скрытые тесты |
| ФСП | Федерация спортивного программирования. Связь идёт через FSP ID и подтягивает достижения, не создавая второй аккаунт |
| ATS | Внешняя система откликов. Платформа опрашивает её и пишет решение обратно. Человек из ATS не становится пользователем KADRY |

Именованные параметры собраны в [параметрах](business/brd/09-parameters.md).
