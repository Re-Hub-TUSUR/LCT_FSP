# Глоссарий

Слова продукта. Строки интерфейса в кавычках — как на экране.

| Термин | Значение |
|--------|----------|
| Категория | Специализация плюс подтверждённый грейд, например «Backend · Middle». Ставится только после опроса и теста. Текст резюме на неё не влияет |
| Потребность | Описание работодателя: кого ищет, чем занимается команда, стек, диапазон грейдов, зарплата. По умолчанию видна только работодателю и служит основой подборки |
| Вакансия | Потребность, которую работодатель опубликовал, чтобы кандидаты могли откликнуться сами |
| Разовое предложение | Скрытая потребность, которую система создаёт сама, когда работодатель приглашает человека из банка без заранее описанной потребности |
| Подборка | Ранжированный список кандидатов под одну потребность. У каждого 2–3 причины попадания |
| Контакты раскрыты | Кандидат принял приглашение этой компании или сам на неё откликнулся. До этого почты и телефона в карточке нет |
| Чат открыт | Кандидат принял приглашение, работодатель принял отклик, или случился взаимный матч. Один чат на пару «кандидат — потребность» |
| Паттерн | Шаблон задания: специализация, уровень, навык и несущие элементы сложности, которые не меняются |
| Вариант | Конкретное задание из паттерна. Меняются только переменные: контекст, числа, формулировки, входные данные |
| Несущие элементы | Неизменная часть паттерна, которая задаёт сложность. Публичные банки задач можно брать только как идею, не как готовый текст |
| Актуальность профиля | Дата последнего подтверждённого действия: теста, регулярной задачи или тестового работодателя |
| Грейд | Один из 11 уровней: Junior− … Head. Подтверждённый грейд ставит тест, который кандидат принял. Система сама грейд не понижает |
| Не подтверждён | Нет засчитанного теста. Такой профиль виден, но всегда ниже подтверждённых |
| Матч | Отклик кандидата на вакансию и добавление его в избранное по этой вакансии, в любом порядке |
| ФСП | Федерация спортивного программирования. Связь идёт через FSP ID и подтягивает достижения, не создавая второй аккаунт |

Именованные параметры (`T_кулдаун`, `N_резюме`, `K_вилка` и остальные) собраны в [параметрах](business/brd/09-parameters.md).
