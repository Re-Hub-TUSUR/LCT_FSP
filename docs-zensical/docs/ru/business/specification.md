# Бизнес-спецификация

## Назначение

Документ фиксирует, что KADRY делает сейчас. Поведение экранов — в [BRD](brd/index.md). Если тексты расходятся, приоритет у BRD.

## Цели

| ID | Цель | Как понять, что получилось |
|----|------|----------------------------|
| G1 | Работодатель сам находит человека | Банк или свайпы → приглашение с вилкой → «Принять» → контакты и чат |
| G2 | Категория не берётся из резюме | Выбор грейда и тест. Без засчитанной попытки категория не подтверждена |
| G3 | Код на тесте проверяется вопросами | После пройденных скрытых тестов — текстовое интервью, если задан ключ модели |
| G4 | Контакты и вилка понятны обеим сторонам | Вилка «от–до» до чата. Контакты только после «Принять» |
| G5 | Вход по почте | Пароль при регистрации, 6-значный код, сессия на refresh-токене |

## Что есть

- Регистрация: почта, пароль от 8 символов, код из письма. Восстановления пароля нет.
- Резюме формой, второе резюме, разбор PDF и DOCX при ключе модели.
- Тест на один из пяти грейдов: 15 или 25 вопросов и одна задача на код, черновик ответа, запуск кода, балл, кулдаун. Для зачёта нужны проходной балл и минимум верных ответов на вопросы. Тест на lead помечен как бета.
- Текстовое интервью: 2–3 вопроса, «Отправить ответы», проход 60 из 100.
- Банк, фильтры, свайпы работодателя и кандидата.
- Приглашение с вилкой, принятие и отклонение, чат, календарь встреч.
- Вакансии: черновик, публикация, взаимный интерес.
- Тестовое компании.
- Опрос ATS: Mock, фильтры платформы, обратная запись.
- Админка: банк заданий, аналитика, проверка компаний, банлист, справочники, параметры, журнал.
- Привязка ФСП в режиме mock.

## Чего нет

Опрос перед тестом, камера и трансляция экрана, голосовое интервью, вход через Яндекс ID и Госуслуги, двухфакторная аутентификация, потребность и версии подборки, заявка «Откликнуться», регулярные задачи, удаление аккаунта, встроенная видеосвязь.
