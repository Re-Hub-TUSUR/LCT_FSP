# Покрытие

Что продукт делает относительно исходного ТЗ. Норматив поведения — [BRD](brd/index.md). Здесь нет обещаний, которых нет в главах.

| Область | Требования | Как это устроено |
|---------|------------|------------------|
| Работодатель сам выходит на человека | FR-Р-02, FR-Р-04, FR-Р-05, FR-К-23 | Банк, свайпы, приглашение с вилкой |
| Категория из теста, не из резюме | FR-К-03, FR-К-13, FR-К-14, FR-К-20 | Пять грейдов, попытка из банка |
| Контакты после согласия кандидата | FR-О-07, FR-К-25 | «Принять» открывает почту этой компании |
| Вилка до чата | FR-О-06 | «от» и «до» в приглашении и вакансии |
| ФСП | FR-К-09, FR-К-10, FR-К-11 | Привязка, импорт, пустой реестр не ошибка |
| Вакансии и взаимный интерес | FR-Р-09, FR-К-26, FR-К-27, FR-К-28 | Публикация, лайк, чат после взаимности |
| Тестовое компании | FR-Р-10, FR-К-29 | Задание кандидату, грейд платформы не меняется |
| ATS | FR-Р-11 | Опрос, наши фильтры, обратная запись, банк не меняется |
| Админка | FR-А-02, FR-А-03, FR-А-05, FR-А-06, FR-А-07, FR-А-08 | Банк заданий, срез, банлист, справочники, журнал |
| Вход через Яндекс ID | FR-О-12 | «Войти через Яндекс», почта подтверждена, имя и портрет в анкете |

В продукт не входят опрос перед тестом, прокторинг, голосовое интервью, 11 грейдов, потребность с версиями подборки, классический отклик, регулярные задачи, 2FA и Госуслуги.
