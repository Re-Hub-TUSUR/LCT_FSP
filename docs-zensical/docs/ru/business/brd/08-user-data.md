# Что мы знаем о пользователе

Откуда берётся поле и можно ли на него опираться. «Подтверждено» значит, что значение получено проверкой, а не только из текста резюме.

## Кандидат

| Поле | Откуда | Подтверждено? |
|------|--------|----------------|
| Почта | Регистрация, код из письма | Да |
| Имя, город, формат, стек, стаж | Резюме | Нет |
| Ожидаемая зарплата | Резюме, необязательно | Нет |
| Грейд и балл теста | Засчитанная попытка | Да |
| Балл текстового интервью | Ответы после теста с рабочим кодом | Да, если интервью запускалось |
| Достижения ФСП | Реестр после привязки | Да, данными реестра |
| Пустая история ФСП | Нет связи или пустой реестр | Да, и это не штраф |
| Статус поиска | Кандидат | Да, его выбор |
| Согласие | Регистрация | Да |

## Работодатель

| Поле | Откуда | Подтверждено? |
|------|--------|----------------|
| Почта | Регистрация, код из письма | Да |
| Название, город, описание | Профиль компании | Нет, пока администратор не подтвердил документы |
| Вакансия и вилка | Форма вакансии | Да, что опубликовано |
| Приглашение | Форма приглашения | Да, что отправлено |
| Внешний отклик ATS | Опрос адаптера | Это не профиль платформы |
