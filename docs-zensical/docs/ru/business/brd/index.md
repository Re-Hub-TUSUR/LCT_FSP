# Business Requirements Document (BRD)

Нормативные требования к целевому поведению KADRY. Это основной источник для продукта, дизайна и разработки. Текущий код описан отдельно в [статусе реализации](../../technical/implementation-status.md) и требования не отменяет.

## Как читать идентификатор

| Префикс | Домен |
|---------|--------|
| FR-О | Общие правила для нескольких ролей |
| FR-К | Кандидат |
| FR-Р | Работодатель |
| FR-А | Администратор |
| UC-* | Сценарий на странице, см. [use cases](../../use-cases/index.md) |
| NFR-* | Измеримое нефункциональное требование |
| П-* | Экран на [карте страниц](../../product/pages.md) |
| T_ P_ N_ L_ W_ K_ F_ R_ Δ_ | Параметр администратора, старт в [главе 09](09-parameters.md) |

**Приоритет** берётся из исходной метки: **MVP** нужно к демо, **Доп** — дополнительный функционал. Метки критериев К1–К6 сохранены рядом с приоритетом.

## Язык продукта

Интерфейс на русском. В обеих локалях этой документации кнопки и статусы приводятся по-русски, как на экране: «Принять», «Не подтверждён», «Отправить приглашение».
