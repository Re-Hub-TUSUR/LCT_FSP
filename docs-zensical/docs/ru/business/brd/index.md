# Business Requirements Document (BRD)

Требования описывают текущий продукт: то, что есть в экранах и API. Новое поведение заводится сюда в том же изменении, что и функция.

## Как читать идентификатор

| Префикс | Домен |
|---------|--------|
| FR-О | Общие правила для нескольких ролей |
| FR-К | Кандидат |
| FR-Р | Работодатель |
| FR-А | Администратор |
| UC-* | Сценарий, см. [use cases](../../use-cases/index.md) |
| NFR-* | Измеримое ограничение |
| П-* | Экран на [карте страниц](../../product/pages.md) |

## Язык продукта

Интерфейс на русском. В обеих локалях этой документации кнопки и статусы приводятся по-русски, как на экране: «Принять», «Отправить ответы», «Опросить».
