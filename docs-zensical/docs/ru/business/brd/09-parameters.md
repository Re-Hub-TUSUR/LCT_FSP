# Параметры

Значения, которые читает код. Часть из них администратор меняет на «Параметрах» (FR-А-07). Старт — то, что задано в настройках API, пока параметр не переопределён.

| Параметр | Что задаёт | Старт |
|----------|------------|-------|
| Длина пароля | Минимум символов при регистрации | 8 |
| Срок refresh | Сколько живёт сессия без нового входа | 30 дней |
| `assessment_retry_days` | Пауза после попытки, которая грейд не подтвердила | 7 дней |
| `assessment_grade_change_days` | Пауза перед сменой уже подтверждённого грейда | 90 дней |
| `assessment_recommend_score` | Балл, с которого открывается следующий грейд | 85 из 100 |
| `interview_minutes` | Время на текстовые ответы | 15 минут |
| `interview_pass_score` | Средний балл ответов, который подтверждает грейд | 60 из 100 |
| Вложение чата | Максимальный размер файла | 10 МБ |
| `reaction_flap_min` | Смены отметки одного кандидата за 10 минут, после которых компания под подозрением | 5 |
| `requisites_churn_min` | Смены реквизитов за сутки | 5 |
| `junk_vacancy_min` | Вакансии без слов за сутки | 2 |
| `meeting_cancel_min` | Отмены встреч за сутки | 5 |
| `chat_media_min` | Файлы работодателя в чате за час | 10 |
| `invalid_industry_min` | Попытки указать направление не из списка | 1 |

Паузы прокторинга, веса «одного промпта», лимиты откликов и регулярных задач в продукте не задаются: этих сценариев нет.
