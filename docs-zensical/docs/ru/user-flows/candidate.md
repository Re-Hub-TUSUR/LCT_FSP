# Путь кандидата

Норматив: [тест](../business/brd/03-assessment.md), [приглашения](../business/brd/04-invitations-chat.md).

## Основной путь

1. «Главная» → «Я ищу работу» → почта, пароль, согласие → код из письма.
2. Резюме: форма или файл → «Сохранить резюме».
3. «Начать тест» → грейд из пяти → задания → при рабочем коде «Отправить ответы».
4. Категория появляется в «Моих категориях».
5. Приглашение → «Принять» → контакты и чат.
6. В чате работодатель может назначить встречу.

## Ветвления

- Без ключа модели резюме заполняется вручную, а пройденный по баллам тест подтверждает грейд без интервью.
- Неудачная попытка не меняет грейд. Следующая — после паузы.
- Высокий балл открывает следующий грейд. Выше lead ступени нет.
- «Отклонить» закрывает приглашение без чата.
- «Не ищу работу» убирает профиль из банка.
- Лайк вакансии и ответ компании открывают чат без отдельной заявки.

## Как устроен тест

| Грейд | Вопросов | Минут | Проходной балл | Минимум по вопросам |
|-------|----------|-------|----------------|---------------------|
| Стажёр | 15 | 28 | 53 | 50 % |
| Junior | 15 | 28 | 64 | 50 % |
| Middle | 25 | 40 | 53 | 60 % |
| Senior | 25 | 45 | 56 | 60 % |
| Lead (бета) | 25 | 50 | 65 | 50 % |

- В каждом тесте одна задача на код. Вопросы дают 80 % балла, код — 20 %.
- Пороги разных грейдов между собой не сравниваются: у старших грейдов вопросов больше и они сложнее.
- Вопрос бывает с несколькими верными вариантами — в нём написано «Выберите все верные». Каждый верный вариант добавляет долю балла, каждый неверный столько же отнимает.
- В задаче «найди ошибку» редактор открывается с программой на Python, TypeScript, Java, C++, C#, Go или PHP. На другом языке решение пишется с нуля.
- После неудачи пауза держит тот же грейд и выше. Тест на грейд ниже можно начать сразу.
- Числа предварительные и уточняются по данным пилота.

## Сбои

Неверный код не пускает в кабинет. Пока человек не ответил, вторая компания может пригласить его, а та же — нет.
