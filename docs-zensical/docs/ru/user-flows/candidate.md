# Путь кандидата

Норматив: [тест](../business/brd/03-assessment.md), [приглашения](../business/brd/04-invitations-chat.md).

## Основной путь

1. «Главная» → «Я ищу работу» → регистрация → письмо → пароль → онбординг.
2. Резюме: PDF или форма → проверка полей → «Сохранить резюме» → баннер «Создайте ещё одно резюме».
3. «Начать тест» → опрос → выбор грейда → проверка оборудования.
4. Тест: первая задача средняя, дальше сложнее или проще → после каждой ИИ-интервью на 2–3 вопроса → результат.
5. «Принять грейд» → категория → «Приглашения».
6. Карточка → «Принять» → контакты → чат.
7. В чате встреча от рекрутера → «Подтвердить» → тестовое, если его отправили → подтверждение найма.

## Ветвления

- Телефон или браузер без трансляции экрана ведёт на «Нужен компьютер». Опрос и грейд на телефоне сохраняются.
- Отказ от теста предупреждает о низком приоритете. Статус «Не подтверждён», баннер «Пройти тест».
- Балл ниже P_минус — предложение теста уровнем ниже. До первого подтверждения N_первичных попыток без паузы.
- Подуровень ниже заявленного — принять или остаться «Не подтверждён».
- Балл не ниже P_уверенно и решена верхняя ступень — предложение теста выше на 7 дней, вне T_кулдаун.
- Флаги прокторинга — «Результат на проверке» до решения в срок T_проверки.
- Несколько резюме — после первого теста предложение теста по следующему. Отказ не трогает первую категорию.
- Отклонение — необязательная причина, обе стороны видят «Отклонено».
- Нет ответа за T_ответ — «Истекло». Отзыв работодателя — «Отозвано», принять нельзя.
- Неудобная встреча — «Попросить перенос» и до 3 слотов.
- Найм — подтвердить или «Это не так». Молчание дольше T_подтверждение_найма найм не засчитывает.

## Дополнительные пути

Связь с ФСП из настроек. Регулярная задача раз в F_регуляр. Лента вакансий со свайпами. Смена грейда после T_кулдаун. Пауза «Не ищу работу». Тестовое из чата до 90 минут.

## Сбои

Ссылка старше 24 часов — письмо ещё раз. PDF не распознан — ручная форма, уже извлечённые поля на месте. Нет камеры, микрофона или экрана — инструкция, тест не стартует. Обрыв дольше 5 минут или трансляция не возобновлена за 60 секунд — «Прервана». Тишина в интервью 30 секунд — повтор, затем 0. Подтверждённое нарушение — «Аннулирована», грейд прежний, пауза T_пауза_нарушение. Утечка — задача на замену без кулдауна. Блокировка — экран «Аккаунт заблокирован».
