# Путь работодателя

Норматив: [подбор](../business/brd/05-employer-matching.md).

## Основной путь

1. «Я нанимаю» → почта, пароль, код → профиль компании.
2. Лента или свайпы: «Интересно» либо открыть карточку.
3. «Отправить приглашение» с вилкой.
4. После «Принять» — контакты и чат. Из чата — встреча или тестовое.

## Ветвления

- Приглашение уходит и без опубликованной вакансии.
- Вакансия публикуется отдельно и попадает в ленту кандидатов.
- Взаимный лайк открывает чат так же, как принятое приглашение.
- «Подключить демо» и «Опросить» разбирают внешние отклики и не кладут их в банк.

## Сбои

Без профиля компании приглашение не создаётся. Повторное приглашение, пока нет ответа, отклоняется.
