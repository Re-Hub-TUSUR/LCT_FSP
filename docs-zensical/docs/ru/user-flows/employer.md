# Путь работодателя

Норматив: [подбор](../business/brd/05-employer-matching.md).

## Основной путь

1. «Я нанимаю» → почта → пароль → обязательная 2FA → профиль компании.
2. «Описать потребность»: роль, специализация, грейды, стек, команда, вилка → «Показать подборку».
3. Категории с числом подтверждённых → люди с 2–3 причинами → фильтры поверх подборки.
4. Карточки: вправо — избранное по потребности, влево — скрыть.
5. Избранное → форма, заполненная из потребности → предпросмотр → «Отправить приглашение».
6. «Отправлено» → «Просмотрено» → «Принято» → контакты → чат.
7. Встреча со ссылкой → расписание у обоих → тестовое по желанию → «Наняли через платформу» → кандидат подтверждает.

## Ветвления

- Нет профиля — «Пригласить» ведёт в профиль и называет пустые поля.
- Нет подтверждённых — соседние категории и «Показать неподтверждённых».
- Правка потребности создаёт версию. Избранное, скрытые и приглашения остаются.
- Приглашение из банка без потребности создаёт разовое предложение.
- Отказ показывает причину. Повтор по той же потребности — через T_повтор_приглашения.
- Нет ответа за T_ответ — «Истекло». Лимит L_приглашений показывает время сброса.
- Отказ или просрочка тестового не влияет на позицию.
- «Наняли вне платформы» — закрытие без подтверждённого найма.
- Отклик и избранное по вакансии в любом порядке — «Взаимный интерес» и чат.

## Дополнительно

Банк с фильтрами. Публикация и разбор откликов. Регулярная задача и приглашение автора решения. Тестовое из чата. Выгрузка в ATS после раскрытия контактов.

## Сбои

Вилка пустая, «до» меньше «от» или шире K_вилка — ошибка у поля. Повтор при активном приглашении — кнопка неактивна. Кандидат удалил аккаунт — «Истекло», «Профиль удалён». Отзыв публикации убирает человека из выдачи за минуту, чат остаётся. «Ограничен» снижает лимит и показывает причину. «Заблокирован» отзывает активные приглашения.
