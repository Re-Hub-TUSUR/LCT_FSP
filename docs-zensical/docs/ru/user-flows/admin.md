# Путь администратора

Норматив: [администратор](../business/brd/07-admin.md).

## Жизненный цикл паттерна

1. Вход → 2FA → «Дашборд валидации».
2. «Создать паттерн»: специализация, уровень, навык, несущие элементы, переменные, способ проверки → «Черновик».
3. «Сгенерировать варианты» → калибровка → отбраковка → проверка «одного промпта» → пометка «Только с интервью» → «Активировать» → «Активен».
4. Алерт утечки или совпадение в выдаче → «Подтвердить утечку» → «Утёк», новые попытки не получают паттерн → затронутые попытки в очереди → замена паттерна.
5. «Эталонные наборы» → «Пересчитать метрики» → дашборд.

## Прокторинг

Очередь от старых к новым → запись с отметками и расшифровка → «Нарушения нет», «Нарушение подтверждено» или «Нужна повторная попытка» → уведомление кандидату.

## Фиктивные вакансии

«Работодатели под подозрением» → сигналы → «Снять подозрение», «Предупредить», «Ограничить» или «Заблокировать». Блокировка пишет запись в банлист.

## Ветвления

Нет калибровки или one-shot — «Активировать» недоступна. Медианный pass rate не ниже P_one_shot_паттерн — паттерн возвращается в «Черновик». Меньше 2 активных паттернов на навык и ступень — предупреждение. Невыданных вариантов меньше 20% — «Заканчиваются варианты». После N_эмп попыток сложность считается по реальным решениям.

## Сбои

Параметр вне диапазона не сохраняется. Используемое значение справочника только архивируется. Себя заблокировать и последнего администратора удалить нельзя.
