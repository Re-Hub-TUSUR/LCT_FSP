# Путь администратора

Норматив: [администратор](../business/brd/07-admin.md).

1. Открыть поддомен админки и ввести имя и пароль в окне браузера. Сразу открыт раздел «Админка»; рядом в меню — «Вакансии».
2. Банк заданий: добавить или поправить карточку, открыть предпросмотр. Карточка предупреждает, если правильный ответ выдаёт себя длиной.
3. Аналитика: снять срез по заданиям и по тестам на грейд. Пересчёт — по кнопке.
4. Компании: подтвердить документы или отказать.
5. Банлист: заблокировать почту, домен или компанию с причиной. Снятие блока — тоже с причиной.
6. Справочники и параметры. Смена параметра пишется в журнал. Пороги тестов живут в шаблонах тестов, их правки тоже попадают в журнал.
7. Журнал выгружается в CSV.
