# Сценарии администратора

Норматив: [администратор](../business/brd/07-admin.md).

## UC-А-01 Вход

**Как** администратор, **я хочу** войти почтой и паролем, **чтобы** открыть админку без второго фактора. FR-А-01.

## UC-А-02 Новое задание

**Как** администратор, **я хочу** нажать «Добавить задание», **чтобы** оно попало в банк платформы. FR-А-02.

## UC-А-03 Срез заданий

**Как** администратор, **я хочу** открыть таблицу заданий, **чтобы** увидеть, как их решали. FR-А-03.

## UC-А-04 Карточка компании

**Как** администратор, **я хочу** подтвердить или отказать по документам компании. FR-А-04.

## UC-А-05 Блокировка

**Как** администратор, **я хочу** заблокировать почту, домен или компанию с причиной. FR-А-05, FR-О-04.

## UC-А-06 Разблокировка

**Как** администратор, **я хочу** снять блок и указать причину, **чтобы** это осталось в истории. FR-А-05.

## UC-А-07 Справочник

**Как** администратор, **я хочу** добавить специализацию или навык либо убрать значение в архив. FR-А-06.

## UC-А-08 Параметр

**Как** администратор, **я хочу** изменить параметр с комментарием, **чтобы** журнал сохранил старое и новое значение. FR-А-07.

## UC-А-09 Журнал

**Как** администратор, **я хочу** открыть журнал и выгрузить CSV. FR-А-08.
