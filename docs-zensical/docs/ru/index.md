## Платформа в двух словах

Работодатель описывает, кого ищет, и сам выходит на кандидата. Кандидат получает **категорию** — связку специализации и грейда — только после опроса и теста, а не из текста резюме. Контакты кандидата компания видит после того, как он принял приглашение или сам откликнулся.

Интерфейс — **React SPA** на русском. API — **FastAPI** за префиксом `/api/v1`, данные в **PostgreSQL**.
