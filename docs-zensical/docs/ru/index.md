## Платформа в двух словах

Работодатель ищет человека в банке и сам выходит на него. Кандидат получает **категорию** — связку специализации и грейда — после теста, а не из текста резюме. Контакты компания видит после того, как кандидат принял приглашение.

Интерфейс — **React SPA** на русском. API — **FastAPI** за префиксом `/api/v1`, данные в **PostgreSQL**.
