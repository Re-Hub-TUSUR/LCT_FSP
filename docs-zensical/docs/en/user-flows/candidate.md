# Candidate path

The rules: [test](../business/brd/03-assessment.md), [invitations](../business/brd/04-invitations-chat.md).

## Main path

1. Home → «Я ищу работу» → email, password, consent → a code from the email.
2. Resume: the form or a file → «Сохранить резюме».
3. «Начать тест» → one of five grades → tasks → «Отправить ответы» when the code works.
4. The category appears in «Мои категории».
5. An invitation → «Принять» → contacts and chat.
6. In the chat the employer can schedule a meeting.

## Branches

- Without a model key the resume is filled by hand, and a test that passed on points confirms the grade without an interview.
- A failed attempt does not change the grade. The next one waits for the pause.
- A high score opens the next grade. There is no step above lead.
- «Отклонить» closes the invitation without a chat.
- «Не ищу работу» removes the profile from the bank.
- A vacancy like and the company's answer open a chat without a separate application.

## Failures

A wrong code does not open the cabinet. While the person has not answered, another company can invite them, and the same company cannot.
