# Administrator path

The rules: [administrator](../business/brd/07-admin.md).

1. Sign in with email and password.
2. Task bank: add or edit a card, open the preview.
3. Analytics: take a snapshot of the tasks.
4. Companies: confirm the documents or refuse.
5. Ban list: block an email, a domain, or a company with a reason. Lifting the block needs a reason too.
6. Dictionaries and parameters. A parameter change is written to the journal.
7. The journal exports to CSV.
