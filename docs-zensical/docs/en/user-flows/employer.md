# Employer path

Normative text: [matching](../business/brd/05-employer-matching.md).

## Main path

1. «Я нанимаю» → email → password → mandatory 2FA → company profile.
2. «Описать потребность»: role, specialization, grades, stack, team, band → «Показать подборку».
3. Categories with a confirmed count → people with 2–3 reasons → filters on top of the shortlist.
4. Cards: right favourites for this need, left hides.
5. Favourites → a form filled from the need → preview → «Отправить приглашение».
6. «Отправлено» → «Просмотрено» → «Принято» → contacts → chat.
7. A meeting with a link → both calendars → an optional take-home → «Наняли через платформу» → the candidate confirms.

## Branches

- No profile — «Пригласить» leads to the profile and names the empty fields.
- No confirmed people — neighbouring categories and «Показать неподтверждённых».
- Editing a need creates a version. Favourites, hidden people, and invitations stay.
- An invitation from the bank without a need creates a one-off offer.
- A decline shows the reason. A repeat on the same need waits T_повтор_приглашения.
- No reply within T_ответ — «Истекло». The limit L_приглашений shows when it resets.
- A refused or expired take-home does not affect rank.
- «Наняли вне платформы» is a closing without a confirmed hire.
- An application and a favourite on a vacancy, in either order — «Взаимный интерес» and a chat.

## Extra

The bank with filters. Publishing and reviewing applications. A recurring task and inviting the author of an answer. A take-home from the chat. An ATS export after contacts are revealed.

## Failures

An empty band, «до» below «от», or wider than K_вилка — an error on the field. A repeat while an invitation is active — the button stays inactive. The candidate deleted the account — «Истекло», «Профиль удалён». Withdrawing publication removes the person from search within a minute; the chat stays. «Ограничен» lowers the limit and shows the reason. «Заблокирован» withdraws active invitations.
