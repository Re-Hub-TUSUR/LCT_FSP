# Employer path

The rules: [search](../business/brd/05-employer-matching.md).

## Main path

1. «Я нанимаю» → email, password, code → company profile.
2. The feed or swipes: «Интересно», or open the card.
3. «Отправить приглашение» with a band.
4. After «Принять» — contacts and chat. From the chat — a meeting or a take-home.

## Branches

- An invitation goes out without a published vacancy.
- A vacancy is published separately and enters the candidate feed.
- A mutual like opens a chat the same way an accepted invitation does.
- «Подключить демо» and «Опросить» screen external applications and do not put them in the bank.

## Failures

Without a company profile the invitation is not created. A second invitation while there is no answer is refused.
