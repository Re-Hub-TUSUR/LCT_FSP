# Glossary

Product words. Quoted interface strings stay in Russian, as on screen.

| Term | Meaning |
|------|---------|
| Category | Specialization plus a confirmed grade, for example «Backend · Middle». Assigned only after the survey and the test. Resume text does not set it |
| Need | The employer's description: who they want, what the team does, stack, grade range, salary. Private by default, and the basis of the shortlist |
| Vacancy | A need the employer published so candidates can apply themselves |
| One-off offer | A hidden need the system creates when the employer invites someone from the bank without a need already written |
| Shortlist | A ranked list of candidates for one need. Each person has 2–3 reasons |
| Contacts revealed | The candidate accepted this company's invitation or applied to it. Until then the card has no email or phone |
| Chat open | The candidate accepted an invitation, the employer accepted an application, or there was a mutual match. One chat per candidate–need pair |
| Pattern | A task template: specialization, level, skill, and the fixed difficulty elements that do not change |
| Variant | One concrete task from a pattern. Only the variables change: context, numbers, wording, inputs |
| Load-bearing elements | The fixed part of a pattern that sets the difficulty. Public task banks may be used only as an idea, not as ready text |
| Profile freshness | The date of the last confirmed action: a test, a recurring task, or an employer take-home |
| Grade | One of 11 levels, from Junior− to Head. A confirmed grade comes from a test the candidate accepted. The system never lowers a grade by itself |
| Unconfirmed | No counted test. The profile is visible and always ranks below confirmed ones |
| Match | The candidate applied to a vacancy and the employer favourited them on that vacancy, in either order |
| FSP | The Federation of Sports Programming. The link goes through FSP ID and imports results. It does not create a second account |

Named parameters (`T_кулдаун`, `N_резюме`, `K_вилка`, and the rest) are listed in [parameters](business/brd/09-parameters.md).
