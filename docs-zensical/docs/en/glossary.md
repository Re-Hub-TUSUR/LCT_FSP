# Glossary

Product words. Interface strings in quotes are as on the screen.

| Term | Meaning |
|------|---------|
| Category | Specialization plus a confirmed grade, for example «Backend · Middle». A counted test sets it. The resume text does not |
| Grade | One of five: intern, junior, middle, senior, lead. A confirmed grade is set by the test. The system does not lower a grade by itself |
| Not confirmed | There is no counted attempt. The profile is visible in the bank, and there is no category |
| Bank | The feed of published profiles for an employer. An external ATS application does not enter it |
| Vacancy | A card the employer published. The candidate likes it or skips it |
| Invitation | A company message to one person: text, band, contact method. Statuses: «Отправлено», «Принято», «Отклонено» |
| Contacts revealed | The candidate pressed «Принять» on that company's invitation. Before that the email is not on the card |
| Mutual interest | The company and the candidate marked each other. A chat opens |
| Interview | 2–3 written questions about the code after a test that passed on points. Not voice and not a call |
| FSP | The sports-programming federation. The link goes through FSP ID and pulls achievements without creating a second account |
| ATS | An external application system. The platform polls it and writes the decision back. A person from the ATS does not become a KADRY user |

Named parameters are collected in [parameters](business/brd/09-parameters.md).
