# Админка KADRY

Один маршрут `/admin` (роль `admin`), разделы переключаются параметром `?tab=`:
`bank`, `task-analytics`, `platform`, `employers`, `banlist`, `settings`, `verification`,
`tests`, `users`. Код: `backend/app/admin/`, `frontend/src/pages/admin/`,
`frontend/src/features/company-verification/` (блок документов в профиле компании).

## Вход

```bash
# в .env или окружении: ADMIN_EMAIL=… ADMIN_PASSWORD=… (пароль от 12 символов)
cd backend && uv run python -m app.admin.create_admin
```

Повторный запуск меняет пароль того же администратора; учётку кандидата или работодателя
команда в администратора не превращает. Вход — обычная форма логина, затем ссылка «Админка».

## Нагрузка

Статистика считается только по кнопке «Пересчитать»: без cron, очередей и автообновления.
Результат сохраняется в `admin_snapshots` (блок, фильтры, дата, JSON), страница показывает
последний снимок «Данные на ДД.ММ.ГГГГ ЧЧ:ММ». Один блок с одними фильтрами — не чаще раза в
5 минут (429 с `nextAllowedAt`), параллельный расчёт отклоняется (409; advisory lock в
PostgreSQL). Агрегация — в базе: `GROUP BY`, `percentile_cont` для медианы, `LAG` для роста
неделя к неделе. CSV берётся из сохранённого снимка (UTF-8 с BOM, `;`).

## Время по заданию

Прохождение теста сообщает, сколько каждое задание было на экране (POST /assessments/attempts/{id}/time,
когда кандидат уходит с задания, скрывает вкладку или завершает тест; скрытая вкладка не считается).
Сервер суммирует время в ssessment_task_times и не даёт ему превысить возраст попытки. Аналитика
берёт время по сданным ответам; попытки до появления учёта в расчёт времени не входят.

## Чего нет в данных

- Варианты задания: кандидатская часть не подставляет переменные и не пишет вариант в
  `assessment_attempts.task_state[task]["variant"]`; до этого все попытки — «основной» вариант.
- У вакансий нет статуса «закрыта с наймом», жалоб нет, приглашения — 501: сигналы «фиктивные
  вакансии» и «жалобы» помечены «нет данных», приглашением считаются лайк кандидату, приглашение и тестовое.
- Поисковые запросы и посещения не логируются (метрики посещаемости не делались).
